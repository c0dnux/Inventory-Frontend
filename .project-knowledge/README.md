## Fast Facts

- **Stack**: React 18 + TypeScript (strict) + Vite 5 + Tailwind CSS 3.4 + React Router v6 + TanStack Query v5 + axios. ESM.
- **Entry points**: `index.html` → `src/main.tsx` → `src/App.tsx`.
- **Dev server**: port **3001**; Vite proxies `/api` → backend (default `http://localhost:3000`).
- **API client**: axios instance at `src/lib/api.ts`, baseURL `VITE_API_URL` (default `/api/v1`), `withCredentials: true` (httpOnly cookies).
- **Auth**: no tokens in JS — backend sets `jwt` / `jwt_refresh` httpOnly cookies; a 401 interceptor silently calls `/auth/refresh`, and on failure dispatches `auth:logout`.
- **RBAC (client)**: nav items + action buttons gated via `hasPermission(user, <typed permission name>)` (e.g. `"products:create"`) against the `PERMISSIONS` table in `src/lib/permissions.ts`; server re-checks on every request.
- **Theming**: dark mode via `.dark` class on `<html>` + `--n-*` CSS variables in `src/index.css`; brand palette is the static `brand.*` Tailwind colors in `tailwind.config.js`.
- **Branding**: single source `src/config/branding.ts` (name "StockPilot", logo mark, currency, locale).
- **Tooling**: ESLint 10 (`npm run lint`), Prettier 3 (`npm run format`), Vitest 4 + RTL (`npm test`). Optimistic mutations via `lib/queryCache.ts`; CSV export via `lib/csv.ts`; interceptor error-toast bus via `lib/toast.ts`.
